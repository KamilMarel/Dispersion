### **Light dispersion simulation**
An app that **simulates the light dispersion phenomenon**, created for my Engineering Thesis. Made with **OpenGL 3.3** and **C++**. The algorithm is based on **real-time rendering papers**.

## Concepts and techniques used in the project
✅ **Dispersion maps**  
✅ **Hierarchical caustic maps**  
✅ **Photon buffers**  
✅ **Photon splatting**  
✅ **Image-space refraction through two interfaces**  
✅ **Render-to-mipmap**  
✅ **Layered rendering**  
✅ **Transform Feedback**  
✅ **Deferred shading**  
✅ **Shadow mapping**  
✅ **Mipmaps**  

## Papers used
- [Real-time Dispersion Rendering Algorithm based on Caustics Map and Single Charge Coupled Device Image Sensor](https://ieeexplore.ieee.org/document/10248466) by Yuanmeng Luo
- [Real-Time Dispersive Refraction with Adaptive Spectral Mapping](https://web.cs.wpi.edu/~emmanuel/publications/PDFs/damon_dispersive_refraction.pdf) by Damon Blanchette and Emmanuel Agu
- [Hierarchical Caustic Maps](https://cwyman.org/papers/i3d08_hcm.pdf) by Chris Wyman
- [An Approximate Image-Space Approach for Interactive Refraction](https://cwyman.org/papers/sig05_approxISRefr.pdf) by Chris Wyman
